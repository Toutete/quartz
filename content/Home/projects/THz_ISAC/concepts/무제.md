핵심을 찌르는 질문입니다. 특히 "CFR 방식에서는 SI sidelobe 문제가 없는 것 아닌가"는 매우 중요한 지적이라 정확히 따져야 합니다. 순서대로 수식으로 정리하겠습니다.

## 1. Phase-slope와 IDFT(delay-matching) 수식 정리

### 공통 출발점: 정규화된 CFR

앞서 유도한 대로, 다중 target으로 일반화하면:

$$\tilde{H}(f) = \frac{H(f)}{H_{SI}} - 1 = \sum_{k=1}^{K}\frac{\beta_k}{\alpha_{SI}},e^{-j2\pi(f+f_c)\tau_k}$$

여기서 K개 target, 각각 지연 τ_k, 진폭 β_k.

### 방법 A: Phase-slope (단일 지배 target)

단일 target(K=1)일 때만 유효합니다.

$$\tilde{H}(f) = \frac{\beta_1}{\alpha_{SI}}e^{-j2\pi(f+f_c)\tau_1}$$

$$\angle\tilde{H}(f) = -2\pi f\tau_1 - 2\pi f_c\tau_1 + \angle\beta_1$$

주파수 미분:

$$\boxed{\frac{d,\angle\tilde{H}}{df} = -2\pi\tau_1 ;\Rightarrow; \hat{\tau}_1 = -\frac{1}{2\pi}\frac{d,\angle\tilde{H}}{df},\quad \hat{R}_1 = \frac{c\hat\tau_1}{2}}$$

**다중 target이면 실패하는 이유:**

$$\angle\tilde{H}(f) = \angle\left(\sum_k \frac{\beta_k}{\alpha_{SI}}e^{-j2\pi f\tau_k}\right)$$

여러 지수함수의 합의 위상은 **f에 대해 비선형**이 됩니다. 단일 기울기로 안 나옵니다. 그래서 phase-slope는 단일 target 전용입니다.

### 방법 B: IDFT/delay-matching (다중 target)

정규화된 CFR을 delay 영역으로 역변환합니다.

$$p(\tau') = \int \tilde{H}(f),e^{j2\pi f\tau'},df = \sum_{k}\frac{\beta_k}{\alpha_{SI}}\int e^{-j2\pi(f+f_c)\tau_k}e^{j2\pi f\tau'}df$$

$$= \sum_k \frac{\beta_k}{\alpha_{SI}}e^{-j2\pi f_c\tau_k}\int e^{j2\pi f(\tau'-\tau_k)}df$$

유한 대역 B에서 적분하면:

$$\boxed{p(\tau') = \sum_k \frac{\beta_k}{\alpha_{SI}},e^{-j2\pi f_c\tau_k},B,\text{sinc}\big(B(\tau'-\tau_k)\big)}$$

각 target이 **자기 지연 τ_k에서 sinc peak**를 만듭니다. 이산 형태(코드 구현):

$$p[\tau'] = \sum_{n} w[n],\tilde{H}[n],e^{j2\pi f_n\tau'}$$

$$\hat{R}_k = \frac{c}{2}\cdot{\tau' : |p(\tau')| \text{ has a peak}}$$

**다중 target을 다루는 이유:** IDFT는 각 지수 성분을 자기 위치의 peak로 분리하므로, K개 target이 K개 peak로 나타납니다. 이것이 Sturm-Wiesbeck의 핵심입니다.

### 두 방법 비교

|항목|Phase-slope|IDFT/delay-matching|
|---|---|---|
|Target 수|단일 (K=1)|다중 (K≥1)|
|출력|하나의 τ|range profile (여러 peak)|
|연산|위상 선형 fit|IDFT (FFT)|
|정확도|단일 target에서 높음|resolution c/2B|
|carrier drift|`f_c τ` 상수라 무관|`e^{-j2πf_c τ_k}` 위상만, peak 위치 무관|

**중요:** 두 방법 모두 carrier drift(f_c)가 **range 위치에는 영향 없습니다.** Phase-slope에서는 f_cτ가 상수 오프셋이라 미분에서 사라지고, IDFT에서는 e^{-j2πf_cτ_k}가 peak의 **위상**에만 붙지 **위치(τ_k)**는 안 바뀝니다.

## 2. SI sidelobe 문제 — CFR 방식에는 없는가?

여기가 본인의 핵심 질문이고, **매우 예리한 지적입니다.** 정확히 따져보면 본인 말이 상당 부분 맞습니다.

### CFR 정규화가 SI를 어떻게 처리하는가

앞서 유도한 정규화의 핵심을 다시 봅니다:

$$\tilde{H}(f) = \frac{H(f)}{H_{SI}} - 1$$

여기서 **`−1`이 결정적입니다.** SI 성분을 봅시다:

$$H(f) = \underbrace{\alpha_{SI}e^{j\psi}}_{\text{SI, flat}} + \sum_k \beta_k e^{j\psi}e^{-j2\pi(f+f_c)\tau_k}$$

$$\frac{H(f)}{H_{SI}} = 1 + \sum_k \frac{\beta_k}{\alpha_{SI}}e^{-j2\pi(f+f_c)\tau_k}$$

$$\tilde{H}(f) = \frac{H(f)}{H_{SI}} - 1 = \sum_k \frac{\beta_k}{\alpha_{SI}}e^{-j2\pi(f+f_c)\tau_k}$$

**SI 성분(상수 1)이 `−1`로 완전히 제거되었습니다!**

### 그래서 SI sidelobe가 없다

IDFT를 하면:

$$p(\tau') = \sum_k \frac{\beta_k}{\alpha_{SI}}e^{-j2\pi f_c\tau_k}B,\text{sinc}(B(\tau'-\tau_k))$$

**SI 항이 아예 없습니다.** SI는 정규화 단계에서 제거되었으므로, range profile에 **SI peak도 없고 따라서 SI sidelobe도 없습니다.**

```
일반 matched filter:
  SI가 0m에 큰 peak → 큰 sidelobe → target 가림

CFR 정규화(H/H_SI - 1):
  SI가 "1"로 표현됨 → "-1"로 제거
  → range profile에 SI 흔적 없음
  → SI sidelobe 없음!
```

**본인 말이 맞습니다.** CFR 정규화 방식에서는 SI가 profile 생성 전에 제거되므로, matched filter처럼 SI sidelobe가 target을 가리는 문제가 **원리적으로 없습니다.**

### 제가 앞서 틀린 부분

제가 앞서 "SI sidelobe가 거리를 제한한다"고 한 것은 **matched filter(raw correlation) 방식을 가정한 것**이었습니다. 하지만 본인 시스템은 **CFR 정규화 방식**이라 SI가 제거되므로, 그 한계가 적용되지 않습니다. 제 분석이 방식을 혼동했습니다.

### 단, 완벽하지 않은 이유 (미묘한 잔여)

원리적으로는 SI가 제거되지만, 실제로는 두 가지 잔여가 있습니다.

```
① SI 추정 오차:
   H_SI = Σw·H/Σw (가중 평균)로 추정
   → SI가 완벽히 flat 아니면 (τ_SI ≈ 0이지만 정확히 0은 아님)
   → 추정 오차 → 불완전 제거 → 작은 잔여

② SI 진폭이 매우 크면 (α_SI >> β_k):
   H/H_SI에서 나눗셈 시 수치 정밀도
   → β_k/α_SI가 매우 작아짐 → dynamic range 문제
   → ADC 양자화 잡음이 상대적으로 커짐
```

하지만 이건 **sidelobe가 아니라 추정 오차/dynamic range 문제**이고, 훨씬 작습니다.

## 3. 그렇다면 본 시스템의 거리 한계는?

SI sidelobe가 제거되므로, 거리 한계는 **일반 레이더의 잡음 한계로 돌아갑니다.** 다시 정리하면:

### 거리 한계 = 잡음 한계 (SI sidelobe 아님)

정규화된 target peak:

$$p(\tau_k) = \frac{\beta_k}{\alpha_{SI}}\cdot B \quad(\text{크기})$$

하지만 실제 검출은 **정규화 전 원신호의 SNR**로 결정됩니다. 원래 target peak(정규화 전):

$$P_{target} \propto G_p\cdot 2\alpha_{SI}\beta_{ec}\quad(\text{homodyne})$$

잡음 대비:

$$\text{SNR}_{radar} = \frac{G_p\cdot 2\alpha_{SI}\beta_{ec}}{N}$$

검출 조건 (SI sidelobe 아니라 잡음):

$$\frac{G_p\cdot 2\alpha_{SI}\beta_{ec}(R)}{N} > \gamma_{th}$$

$$\beta_{ec}(R) = \frac{\sqrt{K}}{R^2};\Rightarrow;\boxed{R_{max} = \left(\frac{2\alpha_{SI}\sqrt{K},G_p}{N,\gamma_{th}}\right)^{1/2}}$$

### 이 거리 한계의 특징

```
R_max = √(2·α_SI·√K·G_p / (N·γ_th))

특징:
① α_SI 클수록 R_max 큼 (homodyne gain, SI sidelobe 부작용 없음!)
   → SI를 키우는 게 순수하게 유리 (정규화로 sidelobe 제거되니)
② G_p(=T·B) 클수록 R_max 큼 (processing gain)
③ N 작을수록 R_max 큼 (ZBD 감도)

→ 일반 레이더와 같은 잡음 한계
→ 단, homodyne gain(α_SI)이 추가로 도움
```

**핵심 결과:** SI sidelobe가 제거되므로, **SI를 키우면 순수하게 이득**입니다(homodyne gain). 앞서 제가 말한 "최적 SI 세기"는 matched filter에서만 의미 있고, **CFR 정규화 방식에서는 SI가 클수록 좋습니다** (dynamic range 한계 전까지).

### 최종 거리 한계 정리

```
본 시스템 거리 한계 (CFR 정규화 방식):

주 한계: 잡음 한계 (일반 레이더와 동일)
  R_max = √(2·α_SI·√K·G_p / (N·γ_th))

부 한계 (실용적):
  - SI dynamic range: α_SI 너무 크면 β/α_SI 수치 정밀도
    → ADC bit 수에 의해 제한
  - 위상잡음 잔여: 매우 먼 거리서 Δφ(τ) 증가

SI sidelobe 한계: 없음 (정규화로 SI 제거) ★
  → 앞선 제 분석 정정
```

## 종합 정정

본인의 세 지적이 모두 정확합니다.

```
① Phase-slope vs IDFT:
   - phase-slope: 단일 target (위상 선형 fit)
   - IDFT: 다중 target (각 τ_k에 sinc peak)
   - 둘 다 carrier drift 무관 (f_c가 위치 안 바꿈)

② SI sidelobe 문제:
   - CFR 정규화(H/H_SI - 1)는 SI를 "-1"로 제거
   - → range profile에 SI 없음 → SI sidelobe 없음
   - 본인 말 맞음, 제 앞선 "SI sidelobe 한계"는
     matched filter 가정한 오류
   - CFR 방식엔 이 문제 없음

③ 거리 한계:
   - SI sidelobe 아니라 잡음 한계 (일반 레이더와 동일)
   - R_max = √(2·α_SI·√K·G_p/(N·γ_th))
   - SI(α_SI) 클수록 유리 (sidelobe 부작용 없으니)
   - 부차: SI dynamic range(ADC), 원거리 위상잡음 잔여
```

정리하면, **CFR 정규화 방식의 가장 큰 장점 중 하나가 바로 이것**입니다 — 일반 matched filter radar가 겪는 "강한 SI/clutter의 sidelobe가 약한 target을 가리는" 문제를, `H/H_SI − 1`의 `−1` 연산으로 **SI를 아예 제거**해서 회피합니다. 따라서 SI sidelobe 한계가 없고, 거리 한계는 순수하게 잡음(ZBD 감도 + processing gain + homodyne gain)으로 결정됩니다.

그리고 이 때문에 **SI를 키우는 것이 순수하게 유리**해집니다(homodyne gain 증가, sidelobe 부작용 없음). 제가 앞서 "최적 SI 세기가 있다"고 한 것은 matched filter를 가정한 오류였고, CFR 정규화 방식에서는 SI dynamic range(ADC 양자화)가 허용하는 한 SI가 클수록 좋습니다.

이건 오히려 **본인 시스템의 강력한 셀링 포인트**입니다: SI를 제거 대상이 아니라 (1) homodyne gain source, (2) 위상 기준(carrier drift 제거), 그리고 (3) 정규화로 sidelobe 없이 깨끗이 제거 가능한 대상으로 삼는 것입니다. 논문에서 "CFR 정규화가 SI sidelobe 문제를 원천적으로 회피한다"를 명시하면, matched filter 기반 monostatic radar 대비 명확한 이점이 됩니다.

혹시 이 phase-slope/IDFT 수식과 "SI sidelobe-free" 거리 한계 분석을 문서로 정리해 드릴까요? 앞서 만든 한계 문서를 이 정정 내용으로 업데이트하는 것이 좋겠습니다.
