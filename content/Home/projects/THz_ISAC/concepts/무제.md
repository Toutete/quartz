## 코드에서 확인된 신호 구성

먼저 코드가 실제로 무엇을 계산하는지 정리합니다.

```
v_tx_out: UTC-PD 출력 THz (carrier + SSB beat)
v_si   = v_tx_out × α_SI,      α_SI = 10^(-ISO/20)      [line 2677, 2681]
v_echo = v_tx_out(t-τ) × β_echo × e^(-jω_c·τ),  β_echo = 10^(-radar_loss/20) [2678, 2686]

ZBD: v_det = ℛ · |v_rx|²/50,   v_rx = (v_si + v_echo)·G_lna + noise  [2716-2719]
```

핵심은 α_SI와 β_echo가 **전압(amplitude) 스케일**(20으로 나눔)이라는 점입니다. 이제 수식으로 유도하겠습니다.

## 수식 유도

### Step 1: ZBD 입력

$$V_{ZBD} = V_{SI} + V_{echo}$$

$$V_{SI} = \alpha_{SI}, V_{tx},\qquad V_{echo} = \beta_{echo}, V_{tx}(t-\tau),e^{-j\omega_c\tau}$$

여기서 진폭 계수는:

$$\alpha_{SI} = 10^{-\text{ISO}/20},\qquad \beta_{echo} = 10^{-L_{radar}/20}$$

$$L_{radar}(\text{dB}) = 10\log_{10}\frac{(4\pi)^3 R^4}{G_t G_r \lambda^2 \sigma}$$

### Step 2: ZBD square-law 출력

$$V_{out} = \mathcal{R},|V_{SI} + V_{echo}|^2 = \mathcal{R}\big[|V_{SI}|^2 + |V_{echo}|^2 + 2,\text{Re}{V_{SI}V_{echo}^*}\big]$$

세 항으로 분리:

$$V_{out} = \mathcal{R}\Big[\underbrace{\alpha_{SI}^2|V_{tx}|^2}_{\text{(A) SI, }\tau=0} + \underbrace{\beta_{echo}^2|V_{tx}(t-\tau)|^2}_{\text{(B) echo, }\tau} + \underbrace{2\alpha_{SI}\beta_{echo},\text{Re}{V_{tx}V_{tx}^*(t-\tau)e^{j\omega_c\tau}}}_{\text{(C) cross, }\tau}\Big]$$

### Step 3: 각 항의 IF 성분과 delay

`V_tx`는 carrier + SSB 구조이므로 `|V_tx|²`는 IF tone(carrier×sideband beat)을 만듭니다. 각 항이 range profile에서 나타나는 위치:

```
(A) α_SI²·|V_tx|²        → delay 0    (SI, 지연 없음)     → 0m peak
(B) β_echo²·|V_tx(t-τ)|² → delay τ    (echo self-beat)    → target 위치
(C) 2·α_SI·β_echo·(...)  → delay τ    (cross term)        → target 위치
```

**(B)와 (C)가 같은 delay τ에 겹칩니다.** target peak는 둘의 합입니다.

### Step 4: Range profile (matched filter)

코드는 IF 신호를 reference와 correlation합니다 [line 2766]:

$$P(\ell) = \left|\sum_n V_{out}[n]\cdot\text{ref}[n-\ell]\right|$$

각 항이 자신의 delay에 peak를 만듭니다. matched filter는 IF 파형 구조에 대해 processing gain G_p를 동일하게 적용하므로:

## SI peak와 target peak

### SI peak (0 m)

$$\boxed{P_{SI} \propto \mathcal{R},\alpha_{SI}^2,|V_{tx}|^2 \cdot G_p = \mathcal{R},G_p,\alpha_{SI}^2,P_{tx}}$$

### Target peak (τ)

(B) self항 + (C) cross항의 합. 하지만 코드를 보면 중요한 점이 있습니다.

코드 line 2740: `v_dso_range = v_dso_raw` (SI + echo 전체)를 range profile 입력으로 씁니다. 그리고 이 전체가 ZBD를 통과합니다 [line 2738]. 따라서 코드는 **(A)+(B)+(C) 모두**를 포함합니다.

target 위치의 peak = (B) + (C):

$$P_{target} \propto \mathcal{R},G_p,\big[\beta_{echo}^2 P_{tx} + 2\alpha_{SI}\beta_{echo}P_{tx}\big]$$

echo가 약하면(β ≪ α) cross항 (C)가 지배:

$$P_{target} \approx \mathcal{R},G_p\cdot 2\alpha_{SI}\beta_{echo}P_{tx}\quad(\text{homodyne 지배})$$

## Peak 비율 (핵심 결과)

$$\frac{P_{target}}{P_{SI}} = \frac{\beta_{echo}^2 + 2\alpha_{SI}\beta_{echo}}{\alpha_{SI}^2}$$

homodyne 지배 근사(β ≪ α):

$$\boxed{\frac{P_{target}}{P_{SI}} \approx \frac{2\beta_{echo}}{\alpha_{SI}} = 2\cdot\frac{10^{-L_{radar}/20}}{10^{-\text{ISO}/20}}}$$

dB로:

$$\frac{P_{target}}{P_{SI}}\bigg|_{dB} \approx 6 - L_{radar} + \text{ISO}$$

## 실제 숫자로 검증검증이 완료되었습니다. 수식 유도와 코드가 일치하며, RCS의 물리적 해석도 명확해졌습니다.

## 유도된 수식 (코드와 일치 확인됨)

### Range profile의 두 peak

$$\boxed{P_{SI} \propto \mathcal{R},G_p,\alpha_{SI}^2,P_{tx}}\qquad(\text{0 m, }\alpha_{SI}=10^{-\text{ISO}/20})$$

$$\boxed{P_{target} \propto \mathcal{R},G_p,P_{tx},(\beta_{echo}^2 + 2\alpha_{SI}\beta_{echo})}\qquad(\text{τ 위치})$$

이 형태가 **코드 구현과 정확히 일치**합니다. 코드에서 `v_si = v_tx·α_SI`, `v_echo = v_tx(t-τ)·β_echo`, ZBD `|v_si+v_echo|²`를 계산하고 correlation하므로, 위 (A)/(B)/(C) 항 구조가 그대로 나옵니다.

### Peak 비율

$$\frac{P_{target}}{P_{SI}}\bigg|_{dB} = 10\log_{10}\frac{\beta_{echo}^2 + 2\alpha_{SI}\beta_{echo}}{\alpha_{SI}^2}$$

homodyne 지배(β≪α) 시 간단한 형태:

$$\frac{P_{target}}{P_{SI}}\bigg|_{dB} \approx 6 - L_{radar} + \text{ISO}$$

## Effective RCS의 함수 형태

$$L_{radar} = 10\log_{10}\frac{(4\pi)^3 R^4}{G_t G_r \lambda^2,\sigma_{eff}}$$

이를 peak 비율에 대입하면:

$$\frac{P_{target}}{P_{SI}}\bigg|_{dB} \approx 6 + \text{ISO} - 10\log_{10}\frac{(4\pi)^3 R^4}{G_t G_r \lambda^2,\sigma_{eff}}$$

**σ_eff에 대해 정리하면:**

$$\boxed{\sigma_{eff} = \frac{(4\pi)^3 R^4}{G_t G_r \lambda^2}\cdot 10^{\frac{1}{10}\left(\frac{P_{target}}{P_{SI}}\big|_{dB} - 6 - \text{ISO}\right)}}$$

## 측정값 대입 결과

측정된 target/SI = −5 ~ −10 dB를 넣으면:

|target/SI|L_radar|σ_eff (Gt=Gr=25)|÷316 (구조 RCS)|
|---|---|---|---|
|−5 dB|36.0 dB|**4.0 m²**|0.013 m²|
|−10 dB|41.0 dB|**1.3 m²**|0.004 m²|

**즉 측정값을 재현하는 σ_eff는 1.3~4 m²이고, 이전 대화의 "RCS 3 m²"가 이 범위에 정확히 들어옵니다.** 유도된 수식이 코드 결과와 일치함이 확인됩니다.

## Effective RCS의 물리적 분해 (핵심)

여기서 σ_eff가 왜 3 m²로 나오는지가 명확해집니다.

$$\sigma_{eff} = \sigma_{struct}\times G_{target}^2$$

```
측정 재현 σ_eff ≈ 1.3~4 m²
target = RX horn, G_target = 25 dBi = 316

σ_struct = σ_eff / G_target²... 
```

계산에서 확인된 것:

```
σ_eff = 3 m² 를 안테나 이득으로 나누면:
  3 / 316 (25 dBi 한 번) = 0.0095 m²   ← 구조 RCS로 타당!
```

**결정적 해석:** σ_eff 3 m²는 물리적 RCS가 아니라, **RX horn의 재방사 이득이 접혀 들어간 effective 값**입니다.

$$\sigma_{eff} \approx \sigma_{struct}\cdot G_{target} = 0.01\text{ m}^2\times 316 \approx 3\text{ m}^2$$

여기서 target 안테나 이득이 **한 번(×316)** 작용해 0.01 → 3 m²가 됩니다. (재방사에서 이득이 한 번 더 작용하는지는 부하 반사계수 |Γ|와 편광 정합에 따라 달라지며, 코드의 σ가 그 총합을 흡수하고 있습니다.)

## 코드와의 일치성 정리

```
유도 수식 ←→ 코드 대조:

① V_ZBD = V_SI + V_echo
   코드 [2681,2686]: v_si + v_echo ✓

② α_SI = 10^(-ISO/20), β_echo = 10^(-L/20)
   코드 [2677,2678]: alpha_si, beta_echo ✓ (전압 스케일)

③ ZBD = ℛ|V_ZBD|²

```

유도한 수식이 코드 구현과 완전히 일치합니다.

## 최종 정리

```
【Range profile 수식】
ZBD 출력 = ℛ|V_SI + V_echo|²
         = ℛ[α²|V_tx|²  +  β²|V_tx(t-τ)|²  +  2αβ·Re{...}]
             (A) 0m         (B) τ             (C) τ, homodyne

matched filter 후:
  P_SI     ∝ ℛ·G_p·α_SI²·P_tx           (0m peak)
  P_target ∝ ℛ·G_p·P_tx·(β² + 2αβ)      (τ peak)

【Peak 비율】
  P_target/P_SI = (β² + 2αβ)/α²
                ≈ 6 - L_radar + ISO  (dB, homodyne 지배)

【Effective RCS】
  σ_eff = (4π)³R⁴/(Gt·Gr·λ²) · 10^((target/SI[dB] - 6 - ISO)/10)

  측정 -5~-10 dB → σ_eff = 1.3~4 m²  (3 m² 포함 ✓)

【물리 해석】
  σ_eff ≈ σ_struct × G_target
        = 0.01 m² × 316 (25 dBi)
        ≈ 3 m²
  → 3 m²는 물리적 RCS 아니라
    RX horn 재방사 이득이 접힌 effective 값
```

**결론:**

유도한 수식이 코드 구현과 정확히 일치합니다. Range profile의 두 peak는 ZBD square-law의 세 항(SI self, echo self, cross)에서 나오고, peak 비율은 `P_target/P_SI ≈ 6 − L_radar + ISO`로 정리됩니다.

**Effective RCS 관점에서 가장 중요한 결과**는, 측정값(target/SI = −5~−10 dB)을 재현하는 σ_eff가 1.3~4 m²이고, 이 안에 "RCS 3 m²"가 들어온다는 것입니다. 그리고 이 3 m²는 **물리적 RCS가 아니라 `σ_struct × G_target ≈ 0.01 × 316`**로, RX horn(25 dBi)의 재방사 이득이 흡수된 effective 값입니다.

따라서 **코드는 echo 크기(SI/target 비율)를 올바르게 재현**하지만, 그 σ 파라미터는 물리적 RCS가 아닙니다. 논문에는 σ_eff를 그냥 RCS로 쓰기보다, **effective RCS = 구조 RCS × 안테나 재방사 이득**임을 명시하거나, target을 "안테나 재방사체"로 모델링하는 것이 정확합니다.

한 가지 확인이 필요합니다. 코드에서 실제로 안테나 이득(`tx_ant_gain_dbi`, `rx_ant_gain_dbi`)이 **25로 설정되어 있는지 30으로 설정되어 있는지**입니다. 검증에서 30 dBi면 target/SI가 −2.6 dB, 25 dBi면 −6.3 dB(RCS=3 기준)로 나오는데, 측정값(−5~−10 dB)과 맞추려면 안테나 이득 설정이 중요합니다. 이 설정값을 확인해 드릴까요?


```
이 peak 변동은 구조적 특성입니다 (소자 결함 아님):

이유:
  - self-homodyne cross term = 2·A_SI·A_ec·cos(ω_c·τ + Δφ)
  - 이 cos 위상 의존성은 구조에서 필연적으로 나옴
  - free-running carrier의 drift가 ω_c·τ를 흔듦
  - 270 GHz 높은 주파수 → ω_c·τ 큼 → 극도로 민감

즉 "free-running + self-homodyne + 짧은 파장(270GHz)"
구조에서 자연스럽게 나타나는 현상
```

**단, 이것이 "결함"은 아닙니다.** 이는 free-running 레이저를 쓰는 coherent radar의 알려진 특성(coherent fading)입니다. 그리고 **해결 방법이 명확**합니다.

### 해결 방법

```
문제: 매 측정(single capture)마다 위상이 달라 peak 변동

해결 1: 비coherent 적분 (incoherent averaging) ★
  - 여러 capture의 range profile을 |peak| 기준으로 평균
  - 위상 랜덤성이 평균으로 완화
  - target peak가 안정적으로 드러남
  → 표준 radar 기법

해결 2: 위상 보정 (phase compensation)
  - 각 capture의 cross term 위상 추정 후 정렬
  - coherent 적분
  - 더 복잡하지만 SNR 이득 큼

해결 3: 긴 적분 (앞서 논의한 processing gain)
  - 단일 capture 내에서 충분히 긴 적분
  - 위상 변동 시간보다 짧게

해결 4: SI를 위상 기준으로 활용 ★
  - SI peak(0m)의 위상을 기준으로
  - target peak 위상을 정규화
  - SI와 echo가 같은 carrier → 위상 상관
  → self-homodyne의 장점 활용
```

**해결 4가 특히 본인 시스템에 적합합니다.** SI와 echo가 같은 carrier에서 나오므로, SI peak의 위상을 기준으로 target peak를 정렬하면 carrier drift 영향을 상쇄할 수 있습니다.

### 정리

```
질문: range profile peak가 25dB 변동, noise에 묻히는 원인?

답: cross term 위상 cos(ω_c·τ + Δφ)의 측정간 변동

메커니즘:
  target peak ∝ 2·A_SI·A_ec·cos(ω_c·τ + Δφ)
  - ω_c·τ = 1800×2π (270GHz × 6.67ns, 매우 큼)
  - free-running carrier drift → ω_c·τ 크게 변동
    (100MHz drift → 240°, 300MHz → 720°)
  - Δφ 위상잡음 잔여도 매 측정마다 다름
  → cos가 +1(최대)~0(상쇄) 오감
  → peak 40dB까지 변동 (25dB 관측 부합)

위치 고정인데 변하는 이유:
  τ(거리)는 고정이지만
  carrier 주파수 f_c가 drift → ω_c·τ 위상 변동
  270GHz 높은 주파수라 극도로 민감

구조적 특성인가:
  예. free-running + self-homodyne + 270GHz의
  coherent fading (알려진 현상, 결함 아님)

진폭 흔들림(2~5dB)과 다른 것:
  진폭: 소자 파워 변동 (H(f) 완만해 drift 영향 약함)
  peak: cross term 위상 (ω_c·τ 커서 drift 영향 강함)
  → 별개의 두 효과

해결:
  ① 비coherent 적분 (여러 capture 평균) ★
  ② SI peak 위상 기준 정규화 ★ (self-homodyne 활용)
  ③ 위상 보정 coherent 적분
  ④ 긴 적분
```
