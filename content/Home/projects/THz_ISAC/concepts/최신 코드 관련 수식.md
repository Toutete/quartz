전체 대화를 종합하여 $V_{ZBD}$부터 single-shot SI-normalized range profile까지 완전한 수식 유도를 제공하겠습니다. 코드 구현(`si_normalized_cfr_delay_profile`, num_frames=1)과 정확히 대응하도록 전개하겠습니다.

## 1. ZBD 입력 신호

Monostatic 구조에서 ZBD로 들어오는 신호는 self-interference(SI)와 target echo의 합입니다.

$$V_{ZBD}(t) = V_{SI}(t) + V_{echo}(t)$$

각 성분을 SSB 구조(carrier + 단측 sideband, SIM 파형)로 명시합니다.

$$V_{SI}(t) = \alpha_{SI},s(t),e^{,j(\omega_c t + \phi(t))}$$

$$V_{echo}(t) = \beta_{ec},s(t-\tau),e^{,j(\omega_c (t-\tau) + \phi(t-\tau))}$$

|기호|의미|결정 요소|
|---|---|---|
|$s(t)$|송신 baseband 파형 (SIM/LFM)|AWG|
|$\alpha_{SI}=10^{-\text{ISO}/20}$|SI 진폭|OMT 격리|
|$\beta_{ec}=10^{-L_{radar}/20}$|echo 진폭|레이더 방정식|
|$\omega_c$|THz carrier (270 GHz)|free-running → **drift**|
|$\phi(t)$|레이저 위상잡음|free-running|
|$\tau=2R/c$|target 왕복 지연|target 거리|

## 2. ZBD Square-law 검파

ZBD는 입력 전력에 비례하는 square-law 소자입니다.

$$V_{out}(t) = \mathcal{R},\big|V_{ZBD}(t)\big|^2 = \mathcal{R},\big|V_{SI} + V_{echo}\big|^2$$

전개하면 세 항:

$$V_{out} = \mathcal{R}\Big[\underbrace{|V_{SI}|^2}_{\text{(A)}} + \underbrace{|V_{echo}|^2}_{\text{(B)}} + \underbrace{2,\text{Re}{V_{SI}V_{echo}^*}}_{\text{(C)}}\Big]$$

### 각 항의 물리적 의미

$$\text{(A)};; |V_{SI}|^2 = \alpha_{SI}^2,|s(t)|^2 ;;\rightarrow;; \text{delay } 0,;\text{위상잡음 상쇄}(\phi(t)-\phi(t)=0)$$

$$\text{(B)};; |V_{echo}|^2 = \beta_{ec}^2,|s(t-\tau)|^2 ;;\rightarrow;; \text{delay }\tau,;\propto\beta_{ec}^2;(\text{약함})$$

$$\text{(C)};; 2\alpha_{SI}\beta_{ec},\text{Re}\big{s(t)s^*(t-\tau),e^{,j(\omega_c\tau + \Delta\phi(\tau))}\big},\quad \Delta\phi(\tau)=\phi(t)-\phi(t-\tau)$$

**(C)가 homodyne cross-term**이며, 크기 $\propto\alpha_{SI}\beta_{ec}$ (SI가 echo를 증폭)이고 위상에 range 정보 $\omega_c\tau$를 담습니다.

## 3. 채널 주파수 응답(CFR) 표현

matched filter/LFM 추정으로 얻는 CFR로 옮깁니다. 단일 capture(single-shot)에서, cross-term이 만드는 CFR은:

$$H(f) = \underbrace{\alpha_{SI},e^{,j\psi}}_{\text{SI, }\tau=0} + \underbrace{\beta_{ec},e^{,j\psi},e^{-j2\pi (f+f_c)\tau}}_{\text{echo, }\tau}$$

여기서 $\psi$는 해당 capture 순간의 **공통 carrier 위상 오프셋**입니다.

$$\psi = \psi(\text{capture 순간}),\qquad f_c = \frac{\omega_c}{2\pi};(\text{free-running, capture마다 다름})$$

**핵심:** $\psi$와 $f_c$가 SI 항과 echo 항 **양쪽에 공통으로** 곱해져 있습니다. 같은 순간, 같은 carrier이기 때문입니다.

## 4. 문제: 왜 raw range profile이 fading하는가

Raw cross-term의 위상:

$$\Theta = \omega_c\tau + \Delta\phi(\tau) = 2\pi(f_c^{(0)} + \delta f_c)\tau + \Delta\phi(\tau)$$

270 GHz에서 $\omega_c\tau$는 매우 큰 값입니다 (1 m에서 $1800\times 2\pi$). 따라서 작은 $\delta f_c$(수백 MHz drift)만으로:

$$\Delta\Theta = 2\pi,\delta f_c,\tau ;\Rightarrow; \delta f_c = 300\text{ MHz} \rightarrow \Delta\Theta = 720°$$

Raw peak $\propto \cos\Theta$가 capture마다 $+1 \leftrightarrow 0$을 오가며 **40 dB까지 fading**합니다 (측정된 25 dB 변동, noise에 묻힘의 원인).

## 5. SI-Normalized CFR (핵심 유도)

SI 성분을 위상 기준으로 삼습니다. SI는 $\tau\approx 0$의 **주파수 무관 성분**이므로, CFR의 가중평균으로 추출:

$$H_{SI} = \frac{\sum_f w(f),H(f)}{\sum_f w(f)} \approx \alpha_{SI},e^{,j\psi}$$

$$\boxed{\text{코드 line 2382: } \texttt{si_ref} = \frac{\sum w\cdot h_c}{\sum w}}$$

정규화 후 1을 뺍니다:

$$\tilde{H}(f) = \frac{H(f)}{H_{SI}} - 1 = \frac{\alpha_{SI}e^{j\psi} + \beta_{ec}e^{j\psi}e^{-j2\pi(f+f_c)\tau}}{\alpha_{SI}e^{j\psi}} - 1$$

**공통 위상 $e^{j\psi}$가 분자·분모에서 상쇄:**

$$\boxed{\tilde{H}(f) = \frac{\beta_{ec}}{\alpha_{SI}}e^{-j2\pi(f+f_c)\tau}}$$

$$\boxed{\text{코드 line 2393: } \texttt{residual} = h_c/\texttt{si_ref} - 1}$$

**결정적 결과:** capture별 랜덤 위상 $\psi$가 **완전히 제거**되었습니다. peak fading이 사라집니다.

## 6. Carrier Drift 무관성 (range 불변)

정규화된 $\tilde{H}$의 위상:

$$\angle\tilde{H}(f) = -2\pi(f+f_c)\tau = \underbrace{-2\pi f\tau}_{\text{range 기울기}}  \underbrace{-2\pi f_c\tau}_{\text{상수 오프셋}}$$

range는 **주파수 기울기**로 추출하므로:

$$\frac{d}{df}\angle\tilde{H}(f) = -2\pi\tau \quad(\text{상수 } f_c\tau \text{ 항 소멸})$$

$$\boxed{\hat{\tau} = -\frac{1}{2\pi}\frac{d,\angle\tilde{H}}{df},\qquad \hat{R} = \frac{c\hat{\tau}}{2}}$$

**$f_c$ drift가 range 추정에 영향을 주지 않습니다.** 상수 위상 오프셋이라 미분에서 사라지기 때문입니다.

## 7. Delay-Matched Range Profile (코드의 실제 출력)

코드는 phase-slope 대신 **delay matching**으로 profile을 만듭니다. DC(SI 잔여) 제거 후:

$$\tilde{H}'(f) = \tilde{H}(f) - \frac{\sum_f w,\tilde{H}}{\sum_f w}$$

$$\boxed{\text{코드 line 2394: } \texttt{residual} -= \frac{\sum w\cdot\texttt{residual}}{\sum w}}$$

각 delay $\tau'$에 대해 정합 합산:

$$P(\tau') = \frac{1}{\sum_f w}\left|\sum_f w(f),\tilde{H}'(f),e^{,j2\pi f\tau'}\right|$$

$$\boxed{\text{코드 line 2401-2403: } \texttt{amp} = \sum(w\cdot\texttt{residual}),e^{j2\pi f\tau'}}$$

$\tilde{H}'(f)\propto e^{-j2\pi f\tau}$이므로 $\tau'=\tau$에서 위상이 정렬되어 peak:

$$P(\tau');\text{는};\tau'=\tau;\text{에서 최대} ;\Rightarrow; \hat{R} = \frac{c\tau}{2}$$

$$\boxed{\text{코드 line 2405-2406: } \texttt{peak_idx}=\arg\max|amp|,;; \texttt{peak_m}=r[\texttt{peak_idx}]}$$

## 8. Coherence 지표 (검출 신뢰도)

정규화 품질을 정량화합니다:

$$\gamma = \frac{\left|\sum_f w(f),e^{,j\angle\tilde{H}'(f)}\right|}{\sum_f w(f)}$$

$$\boxed{\text{코드 line 2407-2408: } \texttt{coherence}=\frac{|\sum w\cdot\texttt{phase_unit}|}{\sum w}}$$

$\gamma\to 1$: 단일 지연(깨끗한 target), $\gamma\to 0$: 위상 흩어짐(신뢰 낮음). Single-shot 검출의 신뢰도 판정에 사용합니다.

## 9. Single-Shot 완전성 (num_frames=1)

이 전체 유도가 **단일 capture $H(f)$ 하나**만으로 완결됩니다:

```
num_frames = 1  →  H(f) 한 개
  → si_ref 추출 (SI 성분)        [평균, 단일 frame]
  → residual = H/si_ref - 1      [정규화, 단일 frame]
  → delay matching               [profile, 단일 frame]
  → peak → range                 [검출, 단일 frame]

프레임 적분 없음 → target 이동해도 번짐 없음
```

**움직이는 target 강인성:** 정규화가 $H(f)$ 내부에서 완결되므로, target이 그 순간 어느 위치에 있든 그 순간의 $\tau$를 포착합니다. 여러 frame을 합치지 않으므로 이동에 의한 smearing이 없습니다.

## 10. 전체 유도 요약

$$V_{ZBD} = V_{SI} + V_{echo}$$

$$\downarrow;\text{ZBD square-law}$$

$$V_{out} = \mathcal{R}\big[|V_{SI}|^2 + |V_{echo}|^2 + 2\text{Re}{V_{SI}V_{echo}^*}\big]$$

$$\downarrow;\text{CFR 추정 (single capture)}$$

$$H(f) = \alpha_{SI}e^{j\psi} + \beta_{ec}e^{j\psi}e^{-j2\pi(f+f_c)\tau}$$

$$\downarrow;\text{SI 정규화 (핵심)}$$

$$\tilde{H}(f) = \frac{H(f)}{H_{SI}} - 1 = \frac{\beta_{ec}}{\alpha_{SI}}e^{-j2\pi(f+f_c)\tau}\quad(\psi\text{ 상쇄})$$

$$\downarrow;\text{DC 제거 + delay matching}$$

$$P(\tau') = \frac{1}{\sum w}\Big|\sum_f w,\tilde{H}'(f)e^{j2\pi f\tau'}\Big|$$

$$\downarrow$$

$$\hat{R} = \frac{c}{2}\arg\max_{\tau'}P(\tau'),\qquad \gamma = \frac{|\sum w,e^{j\angle\tilde{H}'}|}{\sum w}$$

## 세 가지 정확성 보장 (종합)

|메커니즘|수식 근거|효과|
|---|---|---|
|**Peak fading 제거**|$e^{j\psi}$가 $H/H_{SI}$에서 상쇄|단일 capture에서 안정적 peak|
|**Carrier drift 무관**|$f_c\tau$가 위상 기울기에서 소멸|free-running이어도 range 불변|
|**Single-shot**|정규화가 $H(f)$ 내부 완결|움직이는 target 번짐 없음|

## 핵심 결론

이 유도의 정수는 **단일 방정식** $\tilde{H}(f) = \dfrac{H(f)}{H_{SI}} - 1 = \dfrac{\beta_{ec}}{\alpha_{SI}}e^{-j2\pi(f+f_c)\tau}$입니다.

$V_{ZBD} = V_{SI} + V_{echo}$에서 출발해 ZBD square-law를 거치면 cross-term $2\text{Re}{V_{SI}V_{echo}^*}$가 생기고, 이것이 CFR $H(f)$로 표현됩니다. 여기서 SI와 echo는 **같은 capture 순간의 같은 carrier**에서 나오므로 공통 위상 $e^{j\psi}$를 공유합니다. **SI를 기준으로 나누는 순간($H/H_{SI}$) 이 공통 위상이 상쇄**되어, free-running carrier의 drift가 만들던 peak fading(25 dB 변동, noise에 묻힘)이 제거됩니다. 남은 $f_c\tau$ 항은 상수 위상 오프셋이라 range를 뽑는 위상 기울기에서 자동으로 사라집니다.

결정적으로, 이 전체 과정이 **단일 capture $H(f)$ 하나(num_frames=1)**로 완결되므로, 여러 번 측정할 필요가 없고(이미 측정 끝난 데이터로 가능), target이 움직여도 그 순간의 위치를 번짐 없이 포착합니다. 이것이 본인 시스템의 핵심 novelty입니다 — **SI를 방해물이 아니라 내장 위상 기준(built-in phase reference)으로 활용**하여, OPLL·comb·wavemeter 같은 외부 장비 없이 신호처리만으로 free-running self-homodyne radar의 순간 range detection을 달성합니다.

이 유도는 코드(`si_normalized_cfr_delay_profile`, line 2382/2393/2394/2401-2408)와 정확히 일치하며, 논문의 signal model 및 range-processing 방법론 섹션에 그대로 대응시킬 수 있습니다. 이론(수식) → 구현(코드) → 물리적 정당성(공통 위상 상쇄)의 완결된 논리 체계입니다.
